## เกี่ยวกับโปรเจกต์

ผู้ใช้พิมพ์ข้อมูลของตนเป็นภาษาไทยอิสระ เช่น อายุ สัญชาติ อาชีพ สถานะประกันสังคม หรือบุคคลในครอบครัว แล้วระบบจะใช้ AI ร่วมกับฐานความรู้ (RAG) วิเคราะห์ว่า **อาจมีสิทธิ** ประโยชน์ภาครัฐรายการใดบ้าง พร้อมอธิบายเหตุผล เอกสารที่ต้องใช้ ช่องทางติดต่อ และข้อมูลที่ควรตรวจสอบเพิ่ม

> ⚠️ ผลที่แสดงเป็นการประเมินเบื้องต้นเท่านั้น ไม่ใช่การรับรองสิทธิอย่างเป็นทางการ กรุณาติดต่อหน่วยงานที่เกี่ยวข้องเพื่อยืนยัน

**สิทธิที่รองรับ**

1. เบี้ยยังชีพผู้สูงอายุ
2. เบี้ยความพิการ
3. สวัสดิการแห่งรัฐ (บัตรคนจน)
4. ประกันสังคม ม.33 / ม.39 / ม.40
5. เงินอุดหนุนเด็กแรกเกิด
6. สิทธิหลักประกันสุขภาพถ้วนหน้า (บัตรทอง)

## ฟีเจอร์

- กรอกข้อมูลเป็นข้อความอิสระ พร้อมผู้ช่วย AI แนะนำข้อมูลที่ควรเพิ่มระหว่างพิมพ์
- แสดงผลแยกตามสถานะ: อาจมีสิทธิ / อาจมีสิทธิแต่ต้องตรวจสอบเพิ่ม / ยังไม่น่ามีสิทธิ
- แสดงรายละเอียดสิทธิจากฐานข้อมูล (ผลประโยชน์ เอกสาร ช่องทางติดต่อ ลิงก์อ้างอิง)
- โหลดสิทธิที่อาจเกี่ยวข้องเพิ่มเติมได้ตามต้องการ
- คัดลอกผลลัพธ์ และพิมพ์ / บันทึกเป็น PDF
- แดชบอร์ดสถิติการใช้งาน (จำนวนการตรวจสอบ เวลา AI เฉลี่ย หมวดหมู่สิทธิ)
- **PWA:** ติดตั้งลงเครื่องได้ เปิดแบบเต็มจอ และมีหน้าแจ้งเมื่อออฟไลน์
- **Android APK:** ห่อเว็บนี้เป็นแอป (Trusted Web Activity) ด้วย PWABuilder

## สถาปัตยกรรม

```
 ┌──────────────────────┐        ┌────────────────────┐       ┌───────────┐
 │  Frontend (repo นี้)  │  HTTPS │  Backend (Python)  │       │           │
 │  Cloudflare Pages     │ ─────▶ │  Render            │ ────▶ │  Neon DB  │
 │  HTML / CSS / JS      │        │  REST API          │       │ (Postgres)│
 └──────────────────────┘        └────────────────────┘       └───────────┘
      ▲            ▲                       ▲
      │            │                       │
  PWA (เบราว์เซอร์)  APK (Android)   เว็บไซต์เวอร์ชันเดสก์ท็อป
                                   (ใช้ Backend และ DB ชุดเดียวกัน)
```

repo นี้เป็นเฉพาะ **Frontend เวอร์ชันมือถือ** ส่วน Backend และฐานข้อมูลใช้ร่วมกับเว็บไซต์หลัก

ไฟล์ APK เป็นเพียงตัวห่อที่เปิดเว็บบน Cloudflare Pages เนื้อหาจริงอยู่ที่เว็บทั้งหมด ดังนั้น **เมื่อ push โค้ดใหม่ ผู้ใช้ได้เวอร์ชันล่าสุดทันที โดยไม่ต้องติดตั้ง APK ใหม่**

## ติดตั้งลงมือถือ

### ผ่านเบราว์เซอร์ (PWA)

เปิด [Smart Rights Viewer](https://smart-rights-viewer-mobile.pages.dev) บนมือถือ แล้ว

| ระบบ | วิธีติดตั้ง |
|------|-------------|
| Android (Chrome) | กดปุ่ม **ติดตั้งแอปลงเครื่อง** ในหน้าแรก หรือเมนู ⋮ → *Install app* |
| iPhone (Safari)  | กดปุ่ม **Share** → **Add to Home Screen** |

### ผ่านไฟล์ APK (Android)
เปืด [.apk File](https://drive.google.com/file/d/18yRIHYrB_EAtpLxI9LJINnGa-GC1ymms/view?usp=sharing) และติดตั้ง

1. รับไฟล์ `Smart Rights Viewer.apk` จากผู้ดูแลโปรเจกต์ (ไฟล์ APK ไม่ได้เก็บไว้ใน repo)
2. เปิดไฟล์บนมือถือ แล้วอนุญาต **ติดตั้งจากแหล่งที่ไม่รู้จัก** เมื่อระบบถาม
3. หาก Google Play Protect เตือน ให้กด **รายละเอียดเพิ่มเติม** → **ติดตั้งต่อไป**

### เมื่อไรต้องสร้าง APK ใหม่

- **ไม่ต้อง:** แก้ HTML / CSS / JS / ข้อความ ฯลฯ แค่ push แล้ว Cloudflare อัปเดตให้
- **ต้อง:** เปลี่ยนไอคอน ชื่อแอป สีธีม หรือโดเมน — สร้างใหม่ด้วยตัวเลือก **Use mine** (อัปโหลด keystore เดิม) และเพิ่ม **Version code** ขึ้นทีละ 1

## การอัปเดตเวอร์ชัน (สำคัญสำหรับ PWA)

Service Worker จะ cache ไฟล์ของแอป เมื่อแก้ไขไฟล์ใด ๆ ใน `SHELL` ของ `sw.js` ให้เปลี่ยนค่า `VERSION` เพื่อให้เครื่องผู้ใช้ล้าง cache เก่า:

```js
const VERSION = "v2";   // เปลี่ยนทุกครั้งที่ปล่อยเวอร์ชันใหม่
```

ข้อมูลที่เรียกจาก API (`/analyze-rights`, `/suggest-input`, `/stats` ฯลฯ) **ไม่ถูก cache** เพื่อให้ได้ผลล่าสุดเสมอและไม่เก็บข้อมูลส่วนบุคคลไว้ในเครื่อง
